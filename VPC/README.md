# Day 07 – Basic VPC with Public Subnet

## What this creates
- 1 VPC (10.0.0.0/16)
- 1 Public Subnet (10.0.1.0/24)
- 1 Internet Gateway
- 1 Public Route Table with default route (0.0.0.0/0)

## Commands
terraform init
terraform plan
terraform apply
terraform destroy

## Key learning
How VPC, Subnet, IGW, and Route Table work together to provide internet access.
