# Day 06 – Internet Gateway and Route Table

## Objective
Attach an Internet Gateway to a VPC and create a Route Table to enable internet access.

## Resources Created
- aws_vpc
- aws_subnet
- aws_internet_gateway
- aws_route_table
- aws_route_table_association

## What you learned
- IGW enables internet connectivity at the VPC level  
- Route Table controls where traffic goes  
- Associating a Route Table with a subnet makes it “public”

## Commands
terraform init  
terraform plan  
terraform apply  
terraform destroy
