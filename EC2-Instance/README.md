# Create EC2 Instance using Terraform

## Objective
Launch an EC2 instance on AWS using Terraform to understand basic compute provisioning.

## Resources Created
- aws_instance

## Terraform Commands Used
- terraform init
- terraform plan
- terraform apply
- terraform destroy

## Key Learnings
- How to create EC2 using Terraform
- Importance of variables and tfvars
- How outputs help retrieve resource details
- Cost optimization by destroying resources after use
