# Day 17 – Locals + Dynamic Naming + Common Tags

## What this demonstrates

- Use of locals to avoid repetition
- Dynamic resource naming
- Standardized tagging strategy

## Naming pattern

<project>-<environment>-<resource>

Example:
expense-dev-ec2
expense-dev-bucket

## Why this is important

- Cleaner code
- Easy to manage multiple environments
- Industry best practice for tagging

## Commands

terraform init
terraform plan
terraform apply
terraform destroy
